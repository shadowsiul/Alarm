# Alarm

An Alarm clock that silence Alarm on US Federal holidays.
Vibe-coded with Grok and Claude.

##Compatibilty

Android 8 and newer.

## Features

- Create Alarms that can ring on Federal Holidays.

### Personalize:
	- Alarm Sound
	- Snooze Length (5, 10, 15)
	- Auto Turn Off (10, 15)
	- Math Problem for Constant Snoozers



### Language Support

- English
- Spanish
- Chinese
